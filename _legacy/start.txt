Инструкция по запуску проекта maydi_promo:

Шаг 1: Перейдите в директорию проекта
Откройте терминал и перейдите в папку maydi_promo:
cd maydi_promo



Шаг 2: Запустите локальный сервер
Для корректной работы всех функций (аудио, анимации) рекомендуется использовать локальный сервер, а не просто открывать файл index.html. Выберите один из вариантов:



Вариант А: Использование Python (обычно уже установлен в системе)
Запустите команду:
python3 -m http.server 8000



Вариант Б: Использование Node.js (npx)
Запустите команду:
npx serve
или
npx live-server

Шаг 3: Откройте лендинг
После запуска сервера откройте браузер и перейдите по адресу:
http://localhost:8000 (для Python)
или по адресу, который будет указан в консоли (для npx)

Примечание: 
Вы также можете просто открыть файл index.html в браузере (двойным кликом), но некоторые функции интерактивности могут работать некорректно из-за ограничений безопасности браузеров для локальных файлов.
