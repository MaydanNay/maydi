Инструкция по запуску maydi_promo (React SPA)

1. Установите зависимости (один раз):
   npm install

2. Dev-сервер (в WSL):
   bash scripts/dev.sh

   или:
   npm run dev

3. Откройте:
   http://localhost:5180           — главная
   http://localhost:5180/ecosystem — интерактивная экосистема

Сборка:
   npm run build
   npm run preview
